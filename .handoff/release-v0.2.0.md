# dsh-change-review-live v0.2.0

> 功能版：diff 面板按「代码高亮打底、改动只叠背景」重做，上下文改成按需分处展开；同时修掉记录侧的两类噪声（空操作、行尾差异）。

## 本版新增

- **自带按行语法高亮**：插件零依赖，自带 tokenizer（JS/TS/Python/YAML/HTML/Markdown 等），未修改的行也有配色；增/删**只叠背景色**、不再改文字颜色；色弱强化（左侧 3px 色条 + 增行提亮 / 删行压暗 + ± 加粗着色）保留
- **上下文按处分阶段展开**：点某处「省略 N 行」只放**那一处**（贴改动那一端由近及远，夹在两个改动之间时两侧各一半）——第一次 20 行、第二次 50、第三次 100、第四次放完这一处；同段其它省略块、其它文件一行不动。展开后把你点的那一行锚回原处，新放出的行进入视野
- **最新轮次默认整轮展开**：同一轮里改了好几处时不用逐个点开（更早的轮次仍默认折叠；你手动折叠过的以你的操作为准）
- **折叠回拉 + 「最近查看」标记**：折叠看过的卡片会把段头拉回视野，并在段头留一层淡蓝底（只保留最后一条）
- 面板整修：固定头 + 唯一滚动正文、横向滚动下沉到每张卡片内部、折行开关（记住偏好）、段头吸顶、按钮全部图标化

## 本版修复

- **空操作不再进记录**：内容没变的 write/edit、重复写同样内容、old_string 与 new_string 相同的 edit，都不再生成记录（此前会在列表里留下「没有修改」的空条目）
- **行尾差异不算改动**：工具返回值是 LF、磁盘是 CRLF 时，不再把整个文件算成「全删 + 全增」
- **改动行底色铺满整行**：不折行 + 横向滚动时，短改动行的底色不再停在中途、右侧一片空白
- **展开状态不再串台**：上下文展开只作用于点开的那一处；关闭重开、点「刷新」即回到最初状态，而编辑过程中的自动刷新不会把你已展开的内容收起来
- **超大段不再硬截断**：行数上限改为分块 LCS（12000×12000 实测约 190ms 完整返回）；二进制内容（截图等）跳过文本对比
- **审查列表「当前轮次」不再逐行重复用户提问**

## 安装 / 升级

```sh
dsh plugin --profile desktop add github:sujingkpo/dsh-change-review-live
```

本版**同时改了 Host 与浏览器端**：升级后需**重启 DSH Desktop**（记录逻辑与 HTTP 路由都变了）。装到 `dsh web` 的 profile 时把 `desktop` 换成 `web`。
